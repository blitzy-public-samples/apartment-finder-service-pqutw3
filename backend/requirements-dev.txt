# ACCEPTED RESIDUAL ADVISORY - pytest 8.4.2
#   PYSEC-2026-1845 / GHSA-6w46-j5rx-g56g / CVE-2025-71176, CWE-377.
#   Every release through 9.0.2 places its temporary directories under the
#   predictable UNIX path /tmp/pytest-of-<user>, which lets a local user on a
#   shared host cause a denial of service or escalate privileges.
#   First fixed release: 9.0.3, which requires Python 3.10 or later. The
#   interpreter is pinned at 3.9 in five places, so that release is not
#   installable here and no backport is published.
#   Compensating control: pytest.ini at the repository root sets
#   --basetemp=.pytest-basetemp, so the run allocates its temporary
#   directories inside the checkout it owns and never under the shared
#   predictable root the advisory describes. .gitignore excludes that
#   directory, and both .dockerignore files keep it out of images.
#   This advisory is in addition to the seven residual advisories carried by
#   the runtime manifest.
