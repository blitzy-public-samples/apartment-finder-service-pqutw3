# apartment-finder-service - backend runtime dependencies
#
# Runtime: CPython 3.9 (hard pin - see infrastructure/docker/Dockerfile.backend,
# .github/workflows/ci.yml, infrastructure/terraform/main.tf, scripts/deploy.sh and
# the @asyncio.coroutine usage in backend/app/tasks/listing_updater.py).
# Every pin below was verified installable on cp39 / win_amd64 and cp39 / linux.
#
# Pins that are deliberately NOT the newest release:
#   fastapi    - 0.125.0 is the highest release compatible with Pydantic v1.
#                0.126.0+ require Pydantic v2 (verified: ResolutionImpossible).
#                Python 3.9 independently caps fastapi at 0.128.8.
#   pydantic   - frozen on v1: backend/app/core/config.py uses pydantic.BaseSettings,
#                which moved to the separate pydantic-settings package in v2.
#   SQLAlchemy - frozen on 1.4.
#   starlette / python-dotenv - pinned at the Python 3.9 ceiling.
#
# Packages deliberately ABSENT (do not re-add):
#   python-jose    - hard-requires ecdsa (CVE-2024-23342, no patch exists). Use PyJWT.
#   passlib        - unmaintained and raises against bcrypt 5.x. Call bcrypt directly.
#   paypalrestsdk  - deprecated/archived upstream, no webhook verification. Use httpx.
#   requests       - single call site; use httpx (also drops urllib3).
#   python-multipart - not imported anywhere; omitting it avoids six advisories.
