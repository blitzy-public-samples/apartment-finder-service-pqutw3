# Security Remediation Decision Log

This log is the single source of truth for **why** every non-trivial decision in the security
remediation was made. Code comments state only *what* a change defends against and carry a stable
`SEC-NN` identifier; the reasoning lives here, keyed by that identifier. Source code, configuration
files and dependency manifests therefore contain no rationale, and nothing here is duplicated into
them.

A decision is non-trivial if a competent engineer could reasonably have chosen differently. Any
deviation from a literal reading of the requirements gets its own row. An unexplained deviation is a
defect.

**Columns.** *Decision* is what was chosen. *Alternatives considered* names the options rejected.
*Rationale* says why the choice won. *Risk / residual gap* states what the choice leaves open — an
empty cell would mean the decision carries no residual, which is rarely true.

## 2. Dependency audit gate and advisory suppressions

`.github/workflows/ci.yml`

The gate runs `pip-audit --strict --no-deps` against the frozen closure and suppresses a fixed list
of advisories. Suppressing an advisory without a scheduled reconsideration is how a temporary
exception becomes permanent, so **each entry below carries a date and a review trigger, and the
register is part of the deliverable rather than a footnote.**

## 5. Origin allow-list and request-schema decisions (SEC-03, SEC-05)

The settings and request-schema milestone raised one defect and four informational observations. The
defect is closed in code; each observation is a deliberate decision to leave working behaviour alone,
recorded so the omission reads as a choice rather than an oversight. Every value below was measured
against the pinned closure on CPython 3.9.25 on 2026-07-31.

| Decision | Alternatives considered | Rationale | Risk / residual gap |
|---|---|---|---|
| **DL-19** — Extend the `ALLOWED_ORIGINS` entry test in `backend/app/core/config.py` with two terms that reject any entry carrying a non-ASCII, whitespace, or control character. | (a) Leave it, because QA measured the impact as fail-closed.
